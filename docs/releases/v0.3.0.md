# Catena v0.3.0

Catena v0.3.0 is the first practical MVP release candidate. It turns a SQLite database file into a small HTTP and WebSocket API with enough operational tooling to test real developer workflows.

## Highlights

- `POST /query` for parameterized read/write SQL.
- `POST /transaction` for atomic write batches.
- `GET /ws` realtime table subscriptions with operation, affected rows, and timestamp.
- API key authentication with Bearer token, `X-API-Key`, or WebSocket `?token=`.
- Read-only mode, configurable CORS, body limits, query timeout, and rate limit.
- `GET /export` to download a checkpointed SQLite database copy.
- `POST /backup` to create server-side database backups.
- `GET /metrics` for lightweight JSON runtime metrics.
- Embedded admin UI with query runner, result table, realtime log, metrics, backup, and export controls.
- CLI commands: `version`, `init-config`, and `inspect`.
- Minimal JavaScript and Python SDK clients.

## Install

Download the binary for your platform from the release artifacts, then run:

```bash
catena serve --db dev.db --host 127.0.0.1 --port 8080 --api-key dev-secret
```

Open:

```text
http://127.0.0.1:8080
```

## Notes

This release is a developer MVP. It is suitable for local testing, demos, internal tools, and controlled environments. For public deployments, put Catena behind TLS, use a strong API key, set strict CORS, enable rate limiting, and keep regular backups.
