# Pilot Results

Use this table for the first five qualified Catena pilot users.

## Pass Criteria

The first validation round passes only when at least three of five qualified users:

- Already use a workaround.
- Describe the problem without prompting.
- Provide a real or reproducible SQLite scenario.
- Successfully run the Catena pilot.
- Agree that Catena is preferable to their current workaround.

Do not treat stars, generic compliments, page views, or hypothetical interest as validation.
